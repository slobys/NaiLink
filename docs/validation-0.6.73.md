## 页面验证

- 候选前端和最终安装版均在真实 LuCI 框架及路由器只读 API 下检查。受控响应模拟正常、待应用、应用中和失败，覆盖 15 种外窗宽度（320–1800px）、60 组工具栏场景；另检查 18px 根字体、长版本标签、三种内核标签、深浅模式和键盘焦点。
- YouTube/Telegram 保持横排，应用与停止保持同排，操作组没有横向越界。窄屏维护区两列，运行状态在按钮上方；主要触控目标至少高 44px。
- 七种群组宽度使用两张受控对照卡（长/短名称、运行标记和不同延迟状态），确认同高、延迟数值完整。另检查 320px 加大字体、名称浮层完整内容、浮层点击不折叠群组、整卡悬停/移开复原、减少动态效果，以及拖动开始后按 Esc 取消、顺序不变。
- 浏览器不实际请求应用、切换或资源写入；前后全部 11 张表、待应用状态及当前内核/模式一致，临时 LuCI 会话销毁。独立视觉复核结论 ship，仅覆盖本次布局。手机尺寸不等于实体手机实测。

首次安装后复查期间观察到 `groups` / `systems` 产生新的修改及待应用状态变化，校验因此停止，没有用旧快照覆盖；随后以当前数据重新进行只读复查，全部 11 张表和待应用状态保持一致。最初一次独立联网脚本还遇到 Windows 指定本地端口冲突（curl 45），改由系统分配端口、从实际返回的本地 IP/端口匹配转发日志后通过，没有将该工具故障当作代理故障。

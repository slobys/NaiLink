# IPv6 网页加载与节点引导 DNS

## 修复范围

0.6.89 为新建常用分流预设增加 Google、YouTube、GitHub 的完整 GeoSite IPv6 分类规则，放在 CN 直连之前、现有 AI / Netflix 规则之后。其他目的地继续使用原生 IPv6 兜底；已有自定义 IPv6 总出口时，不额外插入这条规则。

升级只补齐 `service-split-v1` 中版本为 0、内容与旧默认逐行一致的预设，允许排版空行与缩进。额外注释、规则、改过的出口、已有编辑版本或非预设均保留。新增分类不可读取或数据库更新失败时保留原记录；再次启动不重复添加。用户维护的旧规则可自行在 CN 直连之前、AI / Netflix 之后加入：

```text
ipversion(6) && domain(geosite:google, geosite:youtube, geosite:github) -> proxy
```

`proxy` 应替换为实际的普通代理群组。保留原生 IPv6 的检测通过，不代表全部 IPv6 请求经代理；代理出口本身的地址族与节点服务器的地址族也不同。

sing-box 和 mihomo 的节点解析现在遵循已填写的 `bootstrap_resolver`，不再固定使用首个网站 DNS 上游。留空时保留原有默认方式；订阅专用节点 HTTPS DNS 保持优先。网站 DNS 上游、请求规则、最终解析器及各自出口不变。

## mihomo 的 IPv6 域名转发

旧适配为保留 `ipversion` 判断关闭目标地址替换，域名仅参与匹配，部分节点仍收到原始 IPv6 地址。单纯重新启用替换会清除路由所用的 IP，使原生 IPv6 兜底失效。行为参见 [mihomo 嗅探文档](https://wiki.metacubex.one/config/sniff/) 和 [固定上游源码](https://github.com/MetaCubeX/mihomo/blob/0455d0d28c4526937380505153e65a843d8612e8/component/sniffer/dispatcher.go)。

0.6.89 配套 `1.19.34-nailink.1` 兼容内核：保留原始 IP 用于规则判断，代理协议发送嗅探域名；直连 TCP / UDP 使用原始地址，不重新解析而改变地址族。不改变认证、TLS 校验、节点和路由内容。

已有 mihomo 文件不会被插件更新静默替换；旧内核保留原行为并显示兼容更新提示，用户需在代理内核窗口检查更新后再切换。新安装 mihomo 使用经校验的兼容包。原 `1.19.33` 和已有版本回执继续有效，避免插件升级造成停机。sing-box 兼容版本保持不变。

隔离实机对照使用相同的原有节点、相同 IPv6 目标与 SNI：原版关闭替换时 Google 的 TLS 失败，开启替换后 Google 恢复，但原生 IPv6 对照变成 IPv4；完整兼容补丁下 Google 返回 204，原生 IPv6 对照仍返回 IPv6。隔离实例仅绑定路由器回环地址，安装中的内核文件和用户配置未修改。该结果是修复方向验证，最终安装包仍需五模式验收。

## 同节点加载慢的排查方法

延迟测试的小请求不能代表整页资源下载或 AI 回答速度。分别比较 IPv4 / IPv6、DNS、TLS、首字节和整页加载，并确认群组实际使用的节点。

节点域名由不同 DNS 解析到不同的机场入口时，同一个节点也可能明显快慢不同。引导 DNS 填写 `IP:端口` 或 `[IPv6]:端口`，更改后应用配置并核对实际入口与联网，不把某一个公共 DNS 设为适合所有用户的默认答案。更换分流后，客户端旧 DNS 缓存可能尚未触发新的域名分流信息；重新查询或刷新缓存后再测。

## 前期实机实验

发布前的配置实验使用 R4S / iStoreOS 25.12.6 / Linux 6.12.112、原有 0.6.87 程序。补齐 IPv6 服务资源与设置节点引导 DNS 后，48 次 IPv4 / IPv6 TCP / UDP DNS 查询通过，浏览器 IPv6 检测 10/10；普通 Chrome 播放器实际视频尺寸为 3840×2160，进度推进至 2 分 19 秒。

实验保留全部节点、订阅、群组及选择；仅调整已授权的路由与节点引导 DNS。QUIC 对照没有显示一致收益，保留原设置。无头 YouTube 播放要求登录确认身份，使用普通已登录 Chrome 补充了实际播放验证；不能把首页 HTTP 200 直接当成播放或 AI 对话成功。

以上属于 0.6.87 上的配置实验，不是 0.6.89 安装包验收。最终构建、摘要、升级保留与三内核验收记录将在正式发布前完成并单独记录。

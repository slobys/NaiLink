连接是否正常

管理面板顶部的百度、Google、OpenAI、GitHub 卡片显示连通状态、HTTP 耗时和最近 18 次记录。绿色表示连接正常，橙色表示响应较慢或网站限制访问，红色表示连接、解析或证书错误。

默认每 30 秒检测一次，仅在面板可见时运行。可以关闭自动检测，需要时点击立即检测。多个页面共享结果，避免重复请求。

检测使用当前内核与已应用的分流规则，不更改节点或设置。这是路由器发起的 HTTP 请求耗时，不是带宽测试；HTTP 403 表示目标有响应但限制访问，不能据此断定节点断线或账号不可用。按设备设置的规则可能与路由器不同。

运行概况怎么看

指标 表示什么
上传 / 下载速度 当前代理实例统计到的传输速率，空闲时可为 0。
活跃连接 当前实例的活动连接情况，不能单独证明目标网站访问成功。
本次流量 / 累计上传下载 当前代理实例累计值。重启代理或应用配置建立新实例后，重新累计。
流量趋势 不同时间范围内的采样；切换 1 分钟、10 分钟等范围，不会单独重置累计流量。
UDP 会话 当前实例维护的 UDP 会话情况。

这些是代理实例的统计，不是路由器全网卡流量或运营商账单。没有流量经过该实例、页面刚打开或网络空闲时，不一定马上出现曲线。

保存、应用和启停的区别

  • 正在保存更改：界面正在保存节点、群组或设置，等待完成后再执行下一步。
  • 应用配置：把保存的修改加载到运行实例，可能启动或重载代理。
  • 启动 / 停止代理：控制代理工作状态，与浏览器退出登录不是同一件事。

重载或停止可能打断已有连接。正在进行重要下载或远程会话时，尽量集中修改后再应用。

电脑、手机与长名称

电脑端可同时查看概况和群组，节点列表按可用宽度调整列数。手机端通过菜单和区域切换查看内容；添加节点窗口的搜索、选择和提交操作保留在容易操作的位置。

  • 电脑：鼠标进入整张节点卡片，可触发溢出名称移动；移开恢复。键盘焦点也可触发。
  • 手机：添加节点窗口支持展开完整名称，其他列表可点击名称查看详情，无需模拟悬停。
  • 减少动态效果：尊重系统设置；动画关闭时，使用完整名称展开或详情查看。
  • 多选：先看“已选”数量，再用“只看已选”确认；切换筛选不会自动取消已有选择。

主题与浏览器偏好

顶部主题入口提供多套配色，并支持浅色、深色与跟随系统。主题和部分显示偏好保存在当前浏览器；换设备、清空浏览器存储或使用隐私模式时，可能需要重新选择。

YouTube 与 Telegram 位于各菜单共用的顶部区域，方便随时查看教程或进入交流群。

日志和问题反馈

“运行日志”可查看最近运行信息。复现问题时记录本次时间、操作和错误分类，避免把旧日志误认为当前失败。

0.6.32 起日志按级别区分：普通信息为蓝色、警告为橙色、错误与严重错误为红色，调试信息使用较弱颜色；页面有文字图例，深色主题也可阅读。续行继承上一条的级别，不把消息内容中的“error”等单词误判成错误。原文仍可直接复制。

日志每 2 秒刷新，打开页面默认定位到底部并跟随最新记录。向上滚动查看历史时，会固定当前内容；新日志仍在后台读取，点击回到最新即可恢复跟随。 也可使用暂停跟随固定画面，方便阅读和复制。读取失败时保留上一次日志并显示提示。

公开反馈前仍需自行复核截图、日志和配置中是否含有订阅 URL、密码、UUID、令牌等凭据。可按问题反馈清单整理信息。

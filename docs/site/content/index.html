v$version 更新说明

本版重点处理 DNS 复用连接失效后的恢复，以及三个内核启动超时、取消和失败清理。现有节点、配置及接管方式继续保留。

  • 切换内核与非 TUN / TUN 模式，区分已选择目标和实际运行状态。
  • 排查首次打开慢，结合 DNS、线路和分流记录判断。
  • 查看当前版本的更新与验证范围，再决定是否升级。

从安装到使用

  1. 确认设备与内核

    CPU 符合只是第一步，eBPF、BTF、固件依赖和可写存储同样重要。

  2. 安装并导入节点

    使用路由器 SSH 安装，在“服务 → NaiLink”添加你自己的节点或订阅。

  3. 绑定群组和路由

    把节点加入 proxy 群组，核对 LAN 接口、DNS 与当前路由方案。

  4. 应用配置，验证结果

    从局域网设备实际访问网站，再看运行概况和日志。

1. 打开管理页面

登录路由器后台，进入 服务 → NaiLink。页面沿用当前 LuCI 登录，不需要额外注册账户，也不用输入内部服务端口。0.6.13 及更早版本的菜单名为 Daed。

四个菜单各管什么？

管理面板看运行概况、管理群组；节点和订阅负责导入与更新；高级设置配置接口、DNS、路由；运行日志查看运行异常。

2. 导入一个确定可用的节点

先用少量节点完成验证，再加入更多订阅：

  • 分享链接：进入“节点和订阅 → 导入节点”，粘贴完整链接后提交。
  • 订阅链接：点击“添加订阅”，填写服务商提供的订阅 URL，提交后等待下载完成。
  • 名称 / 标签：新增时可留空自动识别；手动填写的名称优先。

手动节点显示在“节点”区域；订阅中的节点通过对应订阅的查看节点进入。它们不会全部重复出现在手动节点列表里。

3. 把节点加入 proxy 群组

  1. 回到“管理面板”，找到默认的 proxy 群组。
  2. 点击群组下的添加节点，可先按订阅来源筛选。
  3. 点击节点条目勾选；需要对比时使用单项测试或测试已选。
  4. 点击底部添加所选节点。如果希望整个订阅随更新纳入群组，改用添加订阅组。

新增自定义群组后，还需要让路由规则指向它。仅创建一个名为 AI 的群组，不会自动识别所有 AI 网站。

4. 核对接口、DNS 与路由

  • LAN 接口：局域网设备需要通过 NaiLink 上网时，绑定真实承载该网络的设备。常见桥接设备为 br-lan，请以你自己的固件为准。
  • WAN 接口：默认有 auto 自动检测选项；多拨或自定义上联需要核对实际出站设备。
  • DNS 与路由：先使用默认方案，确认有一套被选中。需要更改分流时，再阅读接口、DNS 与路由。
避免重复接管流量

验证 NaiLink 透明代理时，不要让 PassWall、OpenClash 等另一套透明代理同时接管相同流量。请保留你原来的设置和恢复方式，按需停用原接管后再测试。

5. 应用配置并确认联网

  1. 等待保存完成。顶部出现应用配置时点击它，将已保存的修改加载到代理。
  2. 若仍显示“代理已停止”，点击启动代理。应用配置本身也可能启动代理。
  3. 在连接这台路由器的电脑或手机上，访问一个应直连的网站和一个应走代理的网站。
  4. 回到“运行概况”，观察上传、下载、连接和累计流量；有异常时查看“运行日志”。

节点有延迟、代理显示运行中，并不等于局域网流量已经正确转发。实际访问结果、接口绑定、分流规则和本次日志要结合判断。

接下来

首次设置不必切换内核。需要已适配的其他协议或想比较接管模式时，阅读内核与接管方式，先检查兼容性，再确认切换。

基本联网后，再尝试多选与自动选择策略、订阅自动更新，以及手机管理。遇到问题可直接按现象排查。

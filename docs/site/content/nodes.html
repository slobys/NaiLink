导入和编辑手动节点

进入 节点和订阅 → 导入节点，粘贴服务商或自建服务端提供的完整分享链接。标签选填，留空时读取链接备注；已有节点可从更多菜单进入编辑。

修改时重点核对协议、服务器、端口、认证信息，以及 TLS / SNI、传输方式、混淆等参数。不要把 HTTP 代理端口当成透明代理端口，也不要只改协议名称来“转换”一个节点。

从 0.6.29 起，SS 编辑可直接选择三种 SS2022 加密，填写服务端提供的完整 Base64 密钥；分享链接按 SIP002 编码，普通 AEAD 和 SS2022 使用各自的链接格式。IPv6 地址可带方括号或直接填写。

编辑标准 SS、HY2、AnyTLS、VLESS 等链接时，会保留未改动、未展示的查询参数；VMess JSON 也会保留扩展字段。 修改已知选项时会替换旧别名，关闭 SS 插件时会移除插件参数。保留参数不代表内核已实现对应扩展；SSR 和标准 VMess URI 转换暂不保证完整保留扩展。切换协议后按新协议重新生成，请核对服务端参数。

添加订阅与自动命名

0.6.38 起，导入窗口会显示当前内核支持的协议。点击协议名称可查看格式和限制，手机也能点按查看。 sing-box 增加 Hysteria 1、SSH、Snell 4/6 链接，以及单个出站或封闭出站组合 JSON；ShadowTLS 需配合内层代理使用。 原生 JSON 节点提供完整 JSON 编辑，能等价转换的类型也可供 mihomo 使用。0.6.39 起可在“代理内核”窗口按需安装 Naive HTTPS、WireGuard 和 Tor 扩展包，支持 x86_64 / ARM64。下载约 30 MiB，请预留 400 MiB 存储；Tor 仅 TCP，首次引导较慢。SSR、Juicity 不由 sing-box 实现。

  1. 点击添加订阅，粘贴你的订阅 URL。
  2. 标签可留空。会优先使用订阅返回的名称、文件名等信息，无法识别时回退到链接备注或域名。
  3. 提交后，查看订阅的节点数量和更新时间，点击查看节点进入订阅节点列表。

手动填写的名称优先；后续更新不会自动覆盖已有名称。订阅 URL 是访问凭据，请勿公开发送到群组或问题反馈中。

Clash 订阅格式与限制

0.6.42 起支持含 proxies 列表的 Clash YAML / JSON，也支持 SIP008、普通或 Base64 节点链接列表。已有 Clash 订阅可直接点击更新订阅，无需删除重建。

常见 SS / SS2022、SSR、VMess AEAD、VLESS / REALITY、Trojan、Hysteria2、TUIC v5、AnyTLS、SOCKS5、HTTP(S) 节点会转换为现有节点格式，保留已支持的认证、证书校验、SNI、WebSocket / gRPC 参数。运行时仍以当前内核的兼容性报告为准；不代表所有 Clash 扩展均可使用。

只提取节点，不接管配置中的 DNS、规则、监听或控制端口；不读取本地文件，不自动下载 proxy-providers 引用。如果文件只有外部引用，请向服务商获取包含 proxies 的节点订阅。Clash SSH、WireGuard、Snell 等尚未映射类型可继续用分享链接或已支持的原生节点格式导入。

订阅最多 4 MiB / 4096 节点。未知参数、格式错误、网页响应或保存失败会保留该订阅原有全部节点，并显示中文原因；内容不变时节点 ID 不变，手动加入群组的旧节点也不会被自动删除。失败项可单独重试。

手动与自动更新

订阅卡片上的更新订阅会重新获取节点。更新时间和数量可帮助判断本次更新是否成功；编辑、移除等操作在更多菜单中，链接和自动更新规则可展开详情查看。

自动更新使用 Cron 规则，编辑订阅时配置。例如 10 */6 * * * 表示按路由器本地时间，每 6 小时的第 10 分钟执行。请先确认路由器时间和时区正确。

同一订阅的手动、定时更新会串行处理；下载失败保留原有节点。订阅更新成功后如出现配置变更提示，仍需应用配置。

如何测试节点

  • 单项测试：点击节点卡片的“测试”或结果，再次检查该节点。
  • 当前结果：先用搜索缩小范围，再点击“测试当前结果”。
  • 订阅批量测试：从订阅的查看节点窗口发起，进度显示在对应区域。
  • 停止、继续和重试：使用进度旁的操作；临时请求持续失败时队列会暂停，已有结果保留。

测试的是到检测目标的连接与延迟，不是下载带宽测试。绿色、黄色、红色结果用于快速比较，失败时还可能显示超时、解析失败、证书错误等分类。

大量节点建议先按来源测试，避免同时开多个批次。单个节点失败不等于整个协议不受支持；协议名称相同，服务端参数和线路也可能不同。

协议与配置核对

路由模式整批测试使用后台任务，结果逐条显示；sing-box 共用一个私有测试进程，减少重复启动和排队。 三种内核使用同一 HTTP 测试目标、方法与 3 秒尝试期限；数值包含新建连接和握手耗时，并非 Ping。 停止保留已完成结果，剩余节点可继续；切换内核会取消旧任务，避免结果混淆。

UDP 连通性检查

打开手动节点或订阅节点的详情 → UDP 连通性（可选）→ 测试 UDP，通过该节点向全局 udp_check_dns 目标发送 DNS UDP 请求。结果显示检测目标、时间与单独的延迟或错误分类，既不会覆盖网页测试结果， 也不会切换当前节点、修改群组或分流。仅在主动点击时运行，没有后台轮询。

成功表示该节点能转发这一次 DNS UDP 请求，不代表所有游戏、视频或 QUIC 服务都能使用。失败时还需排除检测目标自身故障、 服务端 UDP 限制和线路丢包，不能仅凭一次检测判断整个协议不可用。

类型 导入后重点检查
SS / SS2022 / SSR 加密方式、完整密码、插件及其参数；服务商专用扩展不能只按 SS 名称判断。
VMess / VLESS / Trojan UUID 或密码、TLS、SNI、Reality、传输方式及路径等组合；VMess 使用 AEAD，alterID 为 0。
Hysteria2 / TUIC / Juicity 认证、TLS、SNI、混淆、端口范围和线路 UDP 条件；TUIC 为 v5。
AnyTLS 密码、SNI、证书校验选项，以及服务端本身是否可达。
SOCKS5 / HTTP(S) / Naive HTTPS 代理地址、认证及 URL 形式；Naive 使用内置实现。

这是配置检查方向，不是对所有服务商和协议扩展的可用性承诺。不要把“跳过证书验证”作为通用修复方案；证书错误先核对 SNI、有效期与设备时间。

搜索、排序与加入群组

节点列表支持按名称、协议或来源搜索，并可切换排序。手动节点在宽栏下以双列显示，窄屏自动调整。紧凑卡片上方显示名称、协议与来源，下方并排放置小型测试结果和轻量加入群组按钮，可选择目标群组，也可在群组内一次多选添加。

电脑上将鼠标移到整个节点卡片，过长名称会滚动显示；移开后恢复。手机点击名称和协议区域可打开详情，查看完整名称。拖动手柄可调整顺序，更多菜单可编辑或移除节点。

把订阅中的单个节点加入群组，和绑定整个订阅是两种操作。需要随订阅更新持续管理一批节点时，优先使用添加订阅组。

Mihomo 内核

0.6.40 新增 mihomo，与 dae、sing-box 在面板切换。按需安装，限 x86_64 / ARM64。导入窗口按当前内核显示已适配协议；支持包含 proxies 列表的 Clash 订阅；导入时只保留节点和受限的节点 DNS 提示，不导入整套分流。兼容性检查通过后才能切换，失败尝试恢复原可用内核，保留节点和配置。

节点入口与延迟

部分 Clash 订阅会为节点域名指定 HTTPS DNS。0.6.57 起，更新订阅时保留这类提示，只作用于该订阅的实际服务器域名；不替换你的网站 DNS、路由或 AI 分流。未包含提示的分享链接和订阅继续使用原解析。

目前接受无认证、证书校验正常的公网 HTTPS DNS，拒绝私网解析器、文件及代理参数。不支持的提示不自动转换为其他解析方式。三个内核复用同一份节点信息，不固定入口 IP。

手动测试标明首连，包含代理握手。详情中的复用耗时仅在确认同一连接后提供。客户端测试地址、首次或复用连接不同时，毫秒数不能直接比较；视频是否流畅仍需看实际传输。

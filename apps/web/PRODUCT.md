# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

OpenWrt、ImmortalWrt、iStoreOS 软路由的管理员，通过电脑和手机浏览器管理家庭或小型网络代理。项目由用户 fork 后独立维护并分享给其他使用者。

## Product Purpose

NaiLink（奶油互联）管理节点、订阅、群组、DNS、路由，显示运行数据和日志，提供升级与规则库维护。

## Operating Context

复用 LuCI 登录。管理员导入节点、加入群组、保存后应用配置，并查看实际生效出口。支持 dae、sing-box、mihomo 及既有接管方式；切换和维护已有备份、兼容性检查与失败回退。

## Capabilities and Constraints

既有 React / TanStack Query / Tailwind / Radix 前端与 Go 后端。保留搜索、来源筛选、多选、排序、延迟测试及暂停续测、长名称查看、节点详情和加入群组等功能。保留节点、订阅、现有路由、未应用修改、所选内核和接管方式；应用配置仍由管理员明确发起。不得新增大型依赖或远程字体、运行时 Logo 请求。

本轮已授权功能包括常用 proxy / AI / Netflix 群组和可重命名的“分流”路由预设。新安装选择分流预设；旧安装通过“常用分流”补齐预设，不替换或自动选中当前路由。AI / Netflix 群组为空时暂用 proxy 的节点，后续可分别添加。用途持久绑定群组 ID，改名不丢失用途，并同步完整的路由目标引用；重复安装预设保留用户后续改名、用途和编辑。

打开群组的添加节点或添加订阅窗口后，按已保存用途自动执行独立入口检查；最多 2 个并发请求，结果使用独立的 10 分钟缓存，按内核、用途、配置/DNS 范围和节点指纹隔离，不覆盖普通延迟结果。提供“只看通过”“勾选通过”“暂停检测”和重新检测；筛选或勾选不会自动提交。订阅选择器可明确选择“仅添加通过的节点”，仍须点击提交。

AI 用途只检查 ChatGPT 入口，不验证账号、登录或其他 AI 服务；Netflix 用途只检查入口，不代表完整播放解锁、地区片库或账号权限。检测结果、未完成、受限和错误须分别呈现，不能把未知当作通过。独立检测不改变当前代理或已应用分流。

视觉继续沿用紧凑控制台：订阅选择器使用紧凑网格，鼠标悬停加深主题色并轻微上浮，不增加整卡外圈；桌面运行概况按可用视口收紧，同时完整保留速率、连接、流量、趋势和累计统计。节点地区图标仅按名称提示在本地识别，不验证出口 IP；当前可确认的运行出口与多选采用独立绿色语义，运行标记不可由草稿群组或测试延迟推断，边缘卡片应完整显示。连接检测已由百度改为阿里云。

## Brand Commitments

保留 NaiLink 名称、频道链接、现有主题选择及深浅模式。用户明确选择 Zashboard / OpenClash 控制面板为视觉参考：紧凑节点卡片、明显选中反馈、清楚的信息层级。连接检测使用阿里云、Google、OpenAI、GitHub 的真实品牌资源，保持原始比例与颜色。

## Evidence on Hand

README.md、用户提供的运行插件截图、现有前端组件与早期实机验证记录。本轮证据为仓库根目录 `.build/service71/browser/`、`.build/service71/browser3.log` 和其中的 `result.json`：节点明暗主题 1800 / 390 / 320px，订阅 1800 / 390 / 320px、320px 键盘焦点、390px 粗指针，以及 1600px 运行概况。

本轮使用原生 LuCI / rpcd 的 API-only 隔离夹具与受控服务响应，验证布局、流程与数据保留；它不证明用户实际服务解锁、真实手机操作或已在路由器部署。示例节点、通过数量和统计值不得宣传为用户的真实连接状态。

## Product Principles

- 已应用配置与编辑中的配置边界清楚。
- 用户数据与正在运行的服务优先保留。
- 紧凑呈现仍须可触控、可键盘操作、可查看长名称。
- 连接状态、节点测试耗时与带宽保持原有含义，不制造数据或能力。
- 自动检查与用户提交分开；保留用途检测边界、结果来源及未完成状态。
